## 📚 Доступные функции

### Эллипс

```cpp
CursorArt::ellipse(width, height);
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `width` | `int` | Определяет горизонтальный радиус эллипса |
| `height` | `int` | Определяет вертикальный радиус эллипса |


Пример:

```cpp
CursorArt::ellipse(150, 75);
```

---

### Спираль

```cpp
CursorArt::spiral(scale, turns);
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `scale` | `float` | Определяет скорость расширения спирали и расстояние между её витками |
| `turns` | `int` | Определяет количество полных оборотов спирали до её повторения |

Пример:

```cpp
CursorArt::spiral(2, 15);
```

---

### Синусоида

```cpp
CursorArt::sinWave(maxPosition);
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `maxPosition` | `int` | Определяет максимальное горизонтальное расстояние движения синусоиды |

Пример:

```cpp
CursorArt::sinWave(500);
```

---
